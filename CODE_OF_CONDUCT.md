# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
That document governs; the summary below is a convenience, not a replacement.

## In short

- Be respectful and considerate. Engage with ideas, not individuals.
- Assume good faith, and accept constructive criticism gracefully.
- Harassment, discriminatory language and personal attacks are not acceptable.
- Do not publish others' private information without their permission.

## Scope

Applies in all project spaces — issues, pull requests, discussions and reviews — and when representing
the project in public.

## Reporting

Report conduct concerns privately by email to **security@iproov.com**, marking the subject line
`HAPS conduct`. This is the same monitored mailbox used for security reports; it is reachable whether
or not GitHub's private reporting form has been enabled.

You may also use GitHub's private reporting form described in [SECURITY.md](SECURITY.md), but that
form is only available once the public repository has enabled it, and it is routed to security
responders. Please do not raise a conduct concern in a public issue or a pull request.

Maintainers are responsible for clarifying these standards and may take proportionate action, up to
removing a contributor from project spaces.
